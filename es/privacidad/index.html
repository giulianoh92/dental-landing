Política de privacidad

Esta página describe qué se recoge cuando se visita el sitio web de Dental Clinic (dental.giulianoh.dev) y cuando se usa la demo en vivo (dental-demo.giulianoh.dev). Dental Clinic es un módulo de clínica dental para Odoo 19.

Última actualización: 2026-10-29.

Responsable

El operador de ambos sitios es Giuliano Hillebrand. Los datos de contacto figuran al final de esta página.

Sitio web (dental.giulianoh.dev)

  • Analítica web. El sitio usa Cloudflare Web Analytics, que no utiliza cookies y ofrece visitas de página agregadas. Cloudflare actúa como encargado del tratamiento.
  • Medición publicitaria. Todas las páginas cargan la etiqueta de Google (gtag.js) de Google Ads, para medir qué campañas publicitarias atraen visitas al sitio. Google puede establecer cookies y recibe la dirección IP, datos del navegador, las páginas visitadas y el clic en el anuncio que originó la visita. Google trata estos datos según su propia política de privacidad; la personalización de anuncios se puede gestionar en adssettings.google.com.
  • Aviso de clics. Cuando se hace clic en un enlace a la ficha de Odoo Apps Store o a la demo en vivo, el navegador envía al servidor de la demo el destino del enlace y la página de origen. Para descartar clics duplicados, el servidor conserva un hash con clave y de corta duración de la dirección IP y del destino; la dirección IP en bruto no se almacena para estos clics. El servidor también registra el país, según lo informado por Cloudflare, y el operador recibe una notificación.
  • Idioma. Si se cambia de idioma, la elección se guarda en el almacenamiento local del navegador con la clave lang_choice.

Demo en vivo (dental-demo.giulianoh.dev)

  • Entorno privado. Cada visitante recibe una base de datos privada de pruebas, que se elimina a los 120 minutos.
  • Sin mensajes salientes. El envío de correo electrónico y SMS está desactivado en la demo.
  • Use datos ficticios. Se pide ingresar en la demo únicamente datos inventados, nunca datos personales o de pacientes reales.
  • Prevención de abuso. La dirección IP se conserva junto con la hora en que se reservó el entorno durante un máximo de 1 día, para aplicar un límite de frecuencia.
  • Registros del servidor. Los registros técnicos del servidor de la demo guardan la dirección IP de cada solicitud. Tienen un tamaño limitado y se rotan automáticamente, por lo que las entradas antiguas se descartan, y se usan solo para operar y proteger el servicio.
  • Estadísticas de uso. Los eventos de actividad (rol, idioma, país y duración) se conservan hasta 30 días. No incluyen la dirección IP.
  • Cookies. La demo establece una cookie de sesión, una cookie CSRF y una cookie demo_lang que guarda la preferencia de idioma.

Publicidad y venta de datos

Ninguno de los dos sitios muestra anuncios y no se venden datos. El sitio web se promociona mediante Google Ads y usa la etiqueta de Google descrita arriba para medir esas campañas.
