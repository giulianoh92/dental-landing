Privacy Policy

This page describes what is collected when you visit the Dental Clinic website (dental.giulianoh.dev) and when you use the live demo (dental-demo.giulianoh.dev). Dental Clinic is an Odoo 19 module for dental practice management.

Last updated: 2026-10-20.

Who is responsible

The operator of both sites is Giuliano Hillebrand. See the contact section below.

Website (dental.giulianoh.dev)

  • Web analytics. The site uses Cloudflare Web Analytics, which is cookieless and reports aggregated page views. Cloudflare acts as processor.
  • Click notification. When you click a link to the Odoo Apps Store listing or to the live demo, your browser sends the link target and the page you were on to the demo server. To discard duplicate clicks, the server keeps a short-lived keyed hash of your IP address and the link target; the raw IP address is not stored for these clicks. The server also records the country, as reported by Cloudflare, and the operator receives a notification.
  • Language choice. If you switch language, the choice is stored in your browser’s local storage under the key lang_choice.

Live demo (dental-demo.giulianoh.dev)

  • Private sandbox. Each visitor receives a private sandbox database, which is deleted after 120 minutes.
  • No outgoing messages. Outgoing e-mail and SMS are disabled in the demo.
  • Use made-up data. Please enter only made-up data in the demo, never real personal or patient data.
  • Abuse prevention. Your IP address is kept together with the time the sandbox was claimed for at most 1 day, to apply a rate limit.
  • Usage statistics. Activity events (role, language, country and duration) are kept for up to 30 days. They do not include the IP address.
  • Cookies. The demo sets a session cookie, a CSRF cookie and a demo_lang cookie that stores your language preference.

Advertising and data sale

There is no advertising on either site, and no data is sold.

Contact

For questions about this policy, use the GitHub profile of Giuliano Hillebrand or the support option of the Odoo Apps Store listing.
